# Imagem de perfil

O arquivo `perfil.svg` é uma imagem provisória.

Para usar uma foto pessoal:

1. Coloque a foto nesta pasta.
2. Use um nome simples, como `minha-foto.jpg`.
3. No arquivo `index.html`, altere:

```html
src="imagens/perfil.svg"
```

para:

```html
src="imagens/minha-foto.jpg"
```

Também atualize o texto do atributo `alt` com o nome da pessoa.
